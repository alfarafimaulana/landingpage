XL IMS Project

Designed and simulated an IP Multimedia Subsystem (IMS) core network to enable VoLTE and Wi-Fi calling services for a mobile virtual network operator (MVNO). This project involved deploying open-source IMS components (Kamailio as P-CSCF/I-CSCF/S-CSCF, FreeSWITCH as MGCF, and Open5GS for HSS integration) on cloud-based virtual machines. Key achievements included configuring SIP registration and session routing, establishing interoperability between IMS and legacy PSTN networks via a media gateway, implementing policy control (PCRF) for QoS enforcement on video calls, and validating call flows (handover between LTE and Wi-Fi) using tools like Wireshark and sipp. The simulated environment successfully supported 100+ concurrent VoLTE sessions, demonstrating seamless handover and HD voice quality, with detailed documentation of network topology, signaling flows, and test results.

XL SBC Project

Designed and deployed an SBC to securely interconnect an on-premises PBX with a cloud VoIP provider, replacing legacy PRI lines. This project involved configuring SIP trunking, implementing security policies to prevent toll fraud and denial-of-service attacks, resolving NAT traversal issues to eliminate one-way audio, and establishing call routing logic. The solution successfully supported 50+ concurrent calls, reduced telecom costs by 40%, and included comprehensive documentation of call flows, troubleshooting logs, and failover testing to ensure high availability.

XL MGCF Project

Designed and simulated a Mobile Originating (MO) Anchoring solution to enable VoLTE subscribers in 2G/3G coverage areas to access IMS multimedia services for outgoing calls. This project involved configuring the OCSI (Originating CS to IMS) functionality in the IMS core to intercept mobile-originated calls from legacy circuit-switched networks and anchor them into the IMS domain via an MGCF (Media Gateway Control Function) and I-CSCF. Key achievements included implementing signaling interworking between ISUP (legacy) and SIP (IMS), establishing routing policies to apply IMS-based charging and supplementary services (call waiting, forwarding) to CS-originated calls, and validating call flows using a test environment comprising a simulated 2G MSC, IMS core (P-CSCF/S-CSCF/TAS), and HSS. The anchored calls successfully retained VoLTE service logic despite originating from legacy access, with detailed documentation of end-to-end signaling flows, SCC-AS anchoring logic, and fallback scenarios for users moving between CS and IMS domains during active sessions.

XL USC/DRA Project

Deployed and configured a Diameter Routing Agent (DRA) to centralize and optimize signaling traffic in a 4G LTE core network environment. This project involved setting up open-source DRA software (such as OpenDiamater or FreeDiameter with routing extensions) on virtual machines, defining routing tables for message types (e.g., CER/CEA, ULR/ULA, RAR/RAA), and implementing load balancing across multiple HSS and PCRF nodes. Key achievements included enabling topology hiding between the home network and roaming partner networks, configuring failover mechanisms to redirect traffic when a Diameter node became unavailable, and testing routing logic using simulated MME, P-GW, and OCS nodes. The solution reduced signaling latency by 25%, prevented single points of failure, and included comprehensive documentation of Diameter message flows, routing rules, and redundancy testing results, demonstrating competence in mobile core signaling and Diameter protocol.

XL New Calling POC

Conducted a technical analysis of Huawei New Calling, a 5G interactive calling solution that adds an IMS Data Channel alongside traditional voice/video to enable real-time translation, AI avatars, visualized menus, and in-call data sharing (images, files, screen captures). The project examined the "1+3+N" architecture (converged core + ultra-HD/AI/interactive capabilities + N services), validated key use cases including scam call prevention and remote healthcare, and documented how this approach transforms the native dialer from a basic communication tool into an intelligent service platform. Deliverables included architecture diagrams, call flow analysis, and a migration roadmap for operators with existing IMS deployments.
